# 🚦 Road Traffic Accident Analysis

> Power BI dashboard analyzing road accident data from Ethiopia

---

## 📌 Project Overview
This project analyzes road traffic accident data to identify patterns in accident severity, driver behavior, vehicle types, and environmental conditions. The goal is to generate actionable insights that help improve road safety and reduce accident risks using data visualization.

---

## 📊 Key Metrics
- 🚗 Total Accidents
- 🧍 Total Casualties
- ⚠️ Serious Injuries
- 🔥 High Risk Cases

---

## 📊 Dashboard Pages

### 🔹 1. Overview Dashboard
- KPI Cards (Total Accidents, Casualties, Injuries)
- Time-based Accident Trends
- Area-wise Accident Distribution

### 🔹 2. Driver & Vehicle Analysis
- Age & Driving Experience Impact
- Gender Distribution of Drivers
- Vehicle Ownership Analysis

### 🔹 3. Road & Environment Analysis
- Road Alignment Impact
- Junction Type Analysis
- Light & Weather Conditions
- Time-based Accident Patterns

---

## 🧠 Key Insights
- Young and less experienced drivers are more prone to accidents
- Two-wheelers are most frequently involved in accidents
- Evening and night hours show peak accident occurrences
- Road and junction conditions significantly influence accident severity

---

## 🚀 Conclusion
This project demonstrates an end-to-end data analytics workflow using Excel and Power BI. It transforms raw accident data into meaningful insights that can help improve road safety and support data-driven decision making.

---

## 🛠️ Tools Used
- Microsoft Excel (Data Cleaning)
- Power BI (Dashboard & Visualization)
